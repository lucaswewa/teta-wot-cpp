# Introduction

`teta-wot-cpp` makes laboratory instruments, and the software around them, available over HTTP as [W3C Web of Things](https://www.w3.org/WoT/) *Things*, from C++. It is a C++ implementation of [teta-wot](https://github.com/lucaswewa/teta-wot): the same features, and the same behaviour on the wire, so a client can't tell which one it is talking to.

It is built on [Drogon](https://github.com/drogonframework/drogon), in C++20, for Windows and Linux.

This guide grows with the implementation. The [plan](https://github.com/lucaswewa/teta-wot-cpp/blob/main/docs/PLAN.md) says what is coming, and in which order.
