## Related software

- [teta-wot](https://github.com/lucaswewa/teta-wot): the Rust implementation, and teta-wot-cpp's reference.
- [LabThings-FastAPI](https://github.com/labthings/labthings-fastapi): the Python framework whose wire behaviour and configuration files teta-wot follows.
- [Eclipse Thingweb node-wot](https://github.com/eclipse-thingweb/node-wot): the reference implementation of the WoT Scripting API, in JavaScript.
- [Drogon](https://github.com/drogonframework/drogon): the HTTP framework teta-wot-cpp serves with.
